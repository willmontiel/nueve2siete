# @nueve2siete/text-shapes

Turns a line of text with emojis into printable 2D shapes, in millimeters: the raised letters, the base that
follows their outline, and an optional key ring loop with its hole. Used by the name keychain; the pencil name
tag will reuse it with a different base.

```ts
const shapes = buildTextShapes('Lucía 🎀', font, { letterHeightMm: 13, borderMm: 2.5, ring: { outerMm: 9, holeMm: 4.5 } })
// shapes.relief, shapes.base (regions with holes), shapes.widthMm, shapes.heightMm
```

It runs the same in the browser (the creator), in tests and in Node (`@nueve2siete/text-shapes/node` loads the
fonts from disk).

## Fonts

In `fonts/`, all under the SIL Open Font License (texts in `fonts/licenses`). Each one includes the Spanish letters
and passes the thin-stroke check at the smallest keychain size (`libs/products` tests):

| Key | Font | File |
|---|---|---|
| `fredoka` | Fredoka Bold | from `@fontsource/fredoka` |
| `pacifico` | Pacifico | from `@fontsource/pacifico` |
| `titan` | Titan One | from `@fontsource/titan-one` |
| `calsans` | Cal Sans SemiBold | static instance of the variable Cal Sans (wght 600), Latin subset, made with fonttools |

To add one: put the `.woff` (not `.woff2`) in `fonts/`, its license in `fonts/licenses`, and add it to `FONTS` and
`FONT_URLS` in `src/fonts.ts`.

## Emojis

`src/emoji-data.ts` is generated by `pnpm build:emojis` (`scripts/build-emojis.ts`):
- The candidates come from Noto Emoji (monochrome, Bold, SIL OFL), plus our own outlines in `CUSTOM_OUTLINES`
  (the solid heart: Noto draws it hatched).
- Each one is checked at the size it has next to 10 mm letters: lines of at least 0.6 mm and gaps of at least
  0.5 mm (0.4 nozzle).
- Only the ones that pass are written, with their outline, so the site doesn't load the emoji font.

To add an emoji, add it to `CANDIDATES` and run the script: the report says whether it passed and why.
