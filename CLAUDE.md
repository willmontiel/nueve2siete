# nueve2siete

Website, admin and custom product creators for nueve2siete 3d studio, a 3D-printing business in Colombia.
Products so far: microphones with a customer's logo, and name keychains. The printer is a Bambu Lab A1 with AMS
Lite (4 colors), with 0.4 / 0.6 / 0.8 mm nozzles. See README.md for setup and the full command list.

## Layout

- `apps/`: what runs.
  - `web/`: the public site (Next.js 16), port 3000.
  - `admin/`: Payload 3 panel and API, port 3001.
  - `engine/`: Python logo engine (FastAPI + OpenCV), port 8000.
- `libs/`: shared TypeScript, consumed as source.
  - `configurator/`: filaments, colors, nozzle limits, microphone definition.
  - `products/`: per-product rules; the keychain for now.
  - `text-shapes/`: text + emojis → printable 2D shapes.
  - `cms/`: Payload config, collections, generated types.
- `dev/db`: local Postgres (embedded, no Docker).

## Commands

- `pnpm dev` starts everything (Postgres, web, admin, engine). `pnpm db` / `pnpm web` / `pnpm admin` / `pnpm engine` start one piece.
- `pnpm test`, `pnpm typecheck` and `pnpm lint` run through Turborepo. `pnpm build` makes the production builds.
- Browser tests: `pnpm --filter @nueve2siete/web test:e2e` and `pnpm --filter @nueve2siete/admin test:e2e`. They reuse the running dev servers.
- `pnpm seed` loads the CMS initial data (idempotent).

## Conventions

- **Language:** code, comments, docs, test names and logs are in English. Customer-facing text and the admin's labels are in Spanish.
- **URLs:** page folders are English and public URLs are Spanish.
  - Every page is in `PAGES` in `apps/web/src/lib/routes.ts`; `next.config.ts` builds the rewrites and redirects from it.
  - Link with `routes.<key>`; never hardcode a Spanish path.
  - A new page needs a new folder plus a `PAGES` entry.
- **Style:** match the surrounding code. No semicolons, single quotes, lines up to about 120 characters, comments explain why.
- **Products are modules:**
  - Rules and validation go in `libs/products/<product>`, UI in `apps/web/src/products/<product>`.
  - Shared UI lives in `apps/web/src/components/ui`: `Popover`, `ColorSelect`, `FontSelect`, `EmojiPicker` and `SegmentedControl`, all on Base UI. Reuse them rather than building new pickers.
  - A new lib must be added to `transpilePackages` in each Next app that imports it.
- **Workflow:**
  - Work in small steps the user validates, and propose a plan before large changes.
  - Commit or push only when asked. The main branch is `master`, not `main`.
  - Never commit `.env` files or `logos-example/` (third-party brands, later real customer logos).

## Gotchas

- **Next.js 16** differs from older versions: read `node_modules/next/dist/docs` (see `apps/*/AGENTS.md`).
- **Payload schema:**
  - Only the admin syncs the schema in development (`buildCmsConfig({ ownsSchema: true })`), and it regenerates `libs/cms/src/payload-types.ts` on start.
  - A schema change that loses data makes Payload prompt, and without a TTY the dev server exits. Drop columns with SQL first.
- **Site data and uploads:**
  - The site reads and writes CMS data through the Local API (`getPayloadClient` from `@nueve2siete/cms`).
  - Files uploaded in the admin go to `MEDIA_DIR` (default `.data/media`) and the site serves them from `app/media/[filename]`.
- **opentype.js:** import it at runtime from `opentype.js/dist/opentype.mjs`, because plain Node picks its CommonJS build, which has no named exports. Its types are in `libs/text-shapes/src/opentype.d.ts`.
- **clipper2-ts** is ESM-only, so scripts must run as ES modules.
- **Emojis:**
  - `libs/text-shapes/src/emoji-data.ts` is generated by `pnpm --filter @nueve2siete/text-shapes build:emojis`: each emoji is checked at the S keychain size with the 0.4 nozzle limits.
  - If the S letter height goes below 10 mm, rerun the script with `--letter-mm`.
- **The example keychain images** in `apps/web/src/assets/products` come from `pnpm --filter @nueve2siete/web assets:keychains`. Rerun it after changing fonts or sizes.
- **Nozzle limits** exist twice: `libs/configurator/src/printer.ts` and `apps/engine/src/engine/printing.py`. Change both.
- **Engine calibration** uses `logos-example/` (gitignored); those tests are skipped when it's missing.
- **Killing local servers:** do it by PID, because `pkill -f` can kill its own shell.
